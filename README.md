# DATA‑BOY Terminal — Setup Instructions

This project runs entirely in your browser. There is no installation, no dependencies, and no server required. Follow these steps to set it up on your computer or host it online.

---

## 1. Download the Project

### Option A — Download ZIP
1. Click the green “Code” button on this repository.
2. Select “Download ZIP”.
3. Extract the ZIP file anywhere on your computer.

### Option B — Clone the Repository
If you use Git:
git clone https://github.com/yourusername/data-boy-terminal

After downloading or cloning, you should see:
index.html

Everything is inside this one file.

---

## 2. Run DATA‑BOY Locally

To run the terminal on your computer:

1. Locate the file:
   index.html
2. Double‑click it.
3. Your browser will open DATA‑BOY automatically.

No setup. No install. No command line. It runs instantly.

---

## 3. Host DATA‑BOY Online (GitHub Pages)

If you want your terminal to be a live website:

### Step 1 — Create a GitHub Repository
1. Log in to GitHub.
2. Click the “+” icon → “New repository”.
3. Name it something like:
   data-boy-terminal
4. Click “Create repository”.

### Step 2 — Upload Your Files
1. In your new repo, click “Add file” → “Upload files”.
2. Upload:
   index.html
3. Click “Commit changes”.

### Step 3 — Enable GitHub Pages
1. Go to “Settings” in your repository.
2. Scroll to “Pages”.
3. Under “Source”, choose:
   Deploy from a branch
4. Select:
   main / root
5. Save.

GitHub will generate a link like:
https://yourusername.github.io/data-boy-terminal/

This link is your live DATA‑BOY terminal.

---

## 4. Editing the Project

All customization happens inside:
index.html

You can open it in any text editor to modify:
- Styles
- Effects
- Settings panel
- Boot sequence
- Terminal behavior

No build tools or frameworks required.

---

## Setup Complete

Once the file is opened locally or deployed with GitHub Pages, DATA‑BOY is fully operational.
